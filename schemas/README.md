# Schema for Module Descriptor Files

The schema in th is directory defines the elements and types to be
used in Module Descriptor Files.

## What are JSON schemas?
The files are JSON files and follow a structure defined by the 
[2020-12 draft](https://json-schema.org/draft/2020-12/json-schema-core).

The [JSON Schema Site](https://json-schema.org/) has more information about
getting started with JSON Schemas.

## Why use JSON schemas?
The schema can be used to validate the Module Descriptor Files. 
The schema can also be used with JSON editors that understand schemas to
write Module Descriptor files and get interactive hints on what elements
are valid.
